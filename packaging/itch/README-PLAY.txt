TERMTD — terminal tower defense

You are Grak, the Last Monster. Hold a dying dragon's lair against twenty
expeditions. All maps and artwork are included in the game binary.

macOS 12 Monterey or newer
  Double-click TERMTD.app or Play.command. The game opens in Terminal.
  You can also run ./Play.command from an existing terminal.

Linux
  In the itch app, click Play to open the game in a terminal window.
  For a browser download, extract the whole folder and run Play.sh. Depending
  on your file manager, enable running executable scripts or open a terminal
  in the folder and run ./Play.sh. From a terminal, ./termtd also works.
  A graphical Play launch needs an installed terminal emulator.

Windows 10/11
  In the itch app, click Play to open the game in a console window.
  For a browser download, extract the whole folder and double-click Play.cmd
  or termtd.exe. From PowerShell in the folder, .\termtd.exe also works.
  Play.cmd keeps startup errors visible before closing the window.
  Windows Terminal is optional; no PowerShell scripts or installer are needed.

Choose the download that matches your computer:
  mac-arm64: Apple Silicon; mac-amd64: Intel Mac
  linux-amd64: Intel/AMD Linux; linux-arm64: ARM Linux
  windows-amd64: Intel/AMD Windows; windows-arm64: ARM Windows

Controls
  Arrows / WASD: move or select     Enter: confirm or place
  1–7: choose a tower              U / X: upgrade / sell
  N: call the next wave            P / F: pause / speed
  J: journal in the lair           Q: quit

Your campaign saves in your home folder and survives replacing this download.
These launchers do not need an installer or change your shell's PATH.

For a command available everywhere, use Homebrew:
  brew install 0xbenc/tap/termtd
  termtd
